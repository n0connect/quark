# Quark Build & Instrumentation Tooling (`tools`)

This directory houses the packaging, instrumentation, automated testing, and validation utilities used to protect target Java applications in the Quark ecosystem.

---

## Tool Index

*   [quark-protect](quark-protect/README.md): Java bytecode instrumenter utilizing **ASM 9** to inject `@QuarkCheckpoint` invocations and mask/XOR method return statements.
*   [quark-build](quark-build/README.md): Class bundler that packages `.class` files into a single, flat unencrypted `app.bundle` format.
*   [e2e-test](e2e-test/README.md): Integration test suite verifying the complete native C++ and JRE launch sequence under multiple success and failure configurations.

---

## Decryption Verification Tools

To aid local diagnostics and confirm that keys generated by `Dev_Keygen` match JRE-level cryptography providers, the root of this folder contains two decryption verification scripts.

These utilities attempt to parse the header of `core.enc`, read the IV, and decrypt the ciphertext under AES-256-GCM using a specified key, dumping the first 16 bytes of plaintext on success.

### 1. Python Validator (`dec_test.py`)
Requires the Python `cryptography` package.
```bash
python dec_test.py <path/to/core.enc> <core_enc_key_hex>
```
Implementation: [dec_test.py](dec_test.py).

### 2. Java Validator (`DecTest.java`)
Uses standard JCE provider structures. Compile and run:
```bash
javac DecTest.java
java DecTest <path/to/core.enc> <core_enc_key_hex>
```
Implementation: [DecTest.java](DecTest.java).
